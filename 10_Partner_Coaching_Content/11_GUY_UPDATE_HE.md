# עדכון קצר לגיא — v1.1 Content Candidate

המשוב שלכם היה במקום. ב־v1.0 שלחנו לכם בעיקר את ספר הכללים, אבל לא ארזנו בתוך אותו handoff את רוב ה־evidence of execution — ה־Journeys, מקרי הכיול, on-call ו־referral files.

ב־v1.1 תיקנו את זה.

## 1. עכשיו יש קובץ COMPLETE אחד

`10_PushApp_v1.1_COMPLETE_QUALITY_EVALUATION.md`

הוא כולל בפנים, ולא רק מפנה החוצה:
- Meta-Coach Master + 24 calibration cases
- Career Master + full Journey + on-call + 14 calibration cases
- Body Image Master + 3 full Journeys + on-call + referral triggers + 21 calibration cases
- Relationships/Loneliness Master + full Journeys + on-call + referral triggers + 20 calibration cases
- Addiction Master + full Journeys + on-call + referral triggers + 22 calibration cases

כל הקבצים עדיין מצורפים גם בנפרד בתוך ה-ZIP, כדי שיהיה נוח לעבוד איתם.

## 2. סגרנו את החור של daily adherence באכילה

הוספנו מנגנון מפורש:

**Observe → choose ONE routine → define daily target/context/frequency/busy-day version → light daily check → weekly Stabilize / Adapt / Progress**

ה-daily check הוא רק:
- Kept it
- Partly
- Didn’t happen

בלי קלוריות, מאקרו, משקל או ציון “יום טוב/רע”.

ב-progression משנים רק דבר אחד בכל פעם:
- תדירות
או
- context

לא שניהם יחד.

אין progression אוטומטי ל-7/7. אם 4–5 ימים משרתים את המטרה ובר-קיימא, זה יכול להיות endpoint. אם check-ins עצמם יוצרים preoccupation/rigidity, מפסיקים או מצמצמים אותם.

הוספנו לזה גם 3 calibration cases ו-evals.

## 3. טריגרי ההפניה עכשיו inline בתוך ה-Master Specs הרגישים

ב-Body Image, Relationships/Loneliness ו-Addiction הוספנו בתוך ה-Master עצמו טבלאות עם:
- trigger
- דוגמאות קונקרטיות למה המשתמש עשוי לומר/לתאר
- מה המאמן עושה
- מה סוג המסר למשתמש

למשל:
- purging/compensation/fainting ב-Body Image
- “אני מפחד להגיד לא”, location tracking, sexual pressure בזוגיות
- unable to wake / slow breathing, alcohol withdrawal, benzo abrupt stop, return to opioids after abstinence ב-Addiction

קבצי ה-referral המלאים עדיין מצורפים גם בנפרד.

## מה נרצה מכם עכשיו

הפוקוס יכול להיות בדיוק מה שביקשתם:
**לשפוט את איכות ה-Journeys עצמם.**

מעניין אותנו במיוחד:
1. האם ה-Journey מרגיש ספציפי מספיק למשתמש ולא generic.
2. האם יש רצף אמיתי בין interview → bottleneck → Milestones → Steps → frequency/progression.
3. האם ה-Steps מספיק התנהגותיים כדי שהמשתמש באמת יוכל לבצע אותם.
4. האם יש מצבים שבהם הכללים שלנו נכונים אבל ה-Journey שנוצר עדיין חלש.
5. אילו calibration cases עדיין חסרים כדי לחשוף את זה.

מבחינתנו זה עכשיו handoff להערכת איכות תוכן, לא handoff טכני.
