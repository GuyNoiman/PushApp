# PUSh Hopper v1

First implementation-ready character package.

## Included
- `model/hopper_v1.glb` — actual 3D GLB with separately named body-part meshes.
- `model/obj_parts/` — editable OBJ parts.
- `assets/push_face_neutral.svg` — exact selected face shape.
- `assets/push_face_neutral.png` — raster reference.
- `character.json` — product and implementation metadata.
- `anchors.json` — clothing/equipment attachment points.
- `skeleton.json` — intended rig hierarchy.
- `materials.json` — PBR starter values.
- `mastery.json` — three visual progression stages.
- `references/hopper_v1_reference.png` — production reference.

## Important
The GLB is a real usable procedural MVP model, not a final hand-sculpted studio asset.
It gives Claude a stable implementation contract and named geometry that can be refined later.

## Non-negotiable
Never alter the exact SVG face path. Material, expression and glow may change; silhouette may not.
