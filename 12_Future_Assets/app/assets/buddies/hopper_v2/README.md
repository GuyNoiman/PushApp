# PUSh Hopper v2 Runtime Export

Responds directly to Claude's feedback:
- GLB with embedded PBR textures
- vertex normals and UVs on every mesh
- Y-up, +Z forward, feet at Y=0
- height approximately 1.05 m
- separate stable mesh names
- smaller inset face screen
- canonical face SVG retained
- anchors, materials and mastery files included

Known limitation: this is still a procedurally modeled MVP, not a hand-sculpted studio asset.
No normal maps, bound skeleton or baked animation clips are included. Because no normal maps are used, tangents are not required.
