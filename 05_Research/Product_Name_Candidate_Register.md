# Product Name Candidate Register

Status: **Living naming register — not a legal or trademark clearance**

Last updated: **2026-08-25**

## Purpose

This file is the permanent source of truth for every product or company name discussed for PushApp. It prevents conversation-only candidates from disappearing and prevents an existing conflicting name from being mistaken for one of our candidates.

No name in this register is approved. A candidate can become a finalist only after current trademark, company, app-store, domain, social-handle, pronunciation, and localization checks.

## Status vocabulary

- **Candidate:** explicitly proposed as a possible name.
- **Reconstructed candidate:** recalled from a naming conversation, but the original conversation wording was not preserved in the repository.
- **Collision reference:** an existing name mentioned only because it may conflict with a candidate.
- **Rejected in preliminary screen:** a candidate with a meaningful exact or near-exact conflict.
- **Worth deeper clearance:** no decisive direct collision found in the preliminary screen; this is not legal availability.
- **Not screened:** retained as an idea but not yet researched.

## Evidence and limits of the history audit

The audit checked:

- the current conversation context available on 2026-08-25;
- `Product_Name_Collision_Screening_2026-08-12.md`;
- repository-wide product, research, decision, and archive documents;
- Git history for the collision-screening document.

The English/compound list above is supported by the preserved preliminary screening, whose stated scope was the names proposed in the founder/Codex naming discussion. The Japanese list was not preserved in that document or an earlier Git revision. It is therefore retained without pretending that its exact historic wording is proven.

## Required process from now on

1. Add every newly proposed name here immediately, even before research.
2. Mark its provenance and never silently upgrade a reconstructed name to confirmed history.
3. Keep candidates separate from collision references.
4. Run preliminary collision screening before placing a name in the leading shortlist.
5. Before adoption, commission formal trademark and linguistic/cultural review in the intended markets.
